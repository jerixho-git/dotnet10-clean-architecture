\# .NET 10 Clean Architecture Reference



This repository provides a \*\*Clean Architecture project structure\*\*

using \*\*.NET 10\*\*, intended as a reference or starting point for

real-world applications.



At this stage, the repository focuses on \*\*architecture setup only\*\*:

solution structure, project boundaries, and dependency direction.



---



\## Purpose



The goal of this repository is to:



\- Demonstrate a \*\*proper Clean Architecture layout\*\* in .NET 10

\- Serve as a \*\*reference / baseline\*\* for future projects

\- Avoid architectural rework by locking boundaries early



This is \*\*not\*\* a full-featured application.



---



\## Architecture



\*\*Architecture Style:\*\* Clean Architecture  

\*\*Target Framework:\*\* .NET 10
